# UI Context — Design Language (VERIFIED against `admin-dashboard/`)

> Purpose: stop AI hallucinating off-brand UI. **Every screen must look like it belongs to this template.** Copy existing screens (`default/`, `crm/`, `finance/`, `chat/`, `file-manager/`) — never invent new visual languages.

## Theme

- **Base**: shadcn **neutral** — near-monochrome zinc scale, light + dark (`.dark` class). Professional government-console feel: white/zinc cards, hairline borders, compact type.
- **Presets** (switchable via `data-theme-preset`, generated by `npm run generate:presets`): `tangerine`, `brutalist` (`neo-brutalism`), `soft-pop`. **Prototype default: neutral.** Do not design around presets; use tokens so all presets work.
- Dark mode is first-class — every new screen must be checked in dark.

## Typography

- **Font**: system stack (`--app-font-sans: ui-sans-serif, system-ui, sans-serif`); headings use `--font-heading` = same stack. **Do not add Google Fonts** without a decision entry.
- **Scale idioms** (copy these): page title `text-3xl tracking-tight`, section `text-sm uppercase text-muted-foreground`, card title `text-sm font-medium`, numbers `tabular-nums` (often `font-mono` for IDs/amounts), body `text-sm`, helper `text-xs text-muted-foreground`.
- Body line length 65–75ch; `text-wrap: balance` on h1–h3.

## Radius & shape

`--radius: 0.625rem`; scale: sm ×0.6, md ×0.8, lg ×1, xl ×1.4, 2xl ×1.8. Cards `rounded-xl`, inputs/buttons default radius, pills/badges `rounded-full`. Card idiom: `shadow-xs` or `shadow-none` + `border` (NOT heavy shadows).

## Layout patterns (copy exact rhythms)

1. **Dashboard shell** (`dashboard/route.tsx`): collapsible sidebar (`sidebar-items.ts` data) + header (search dialog, layout controls, theme switcher, account switcher) + `<Outlet/>`. MVP edits nav data only.
2. **Screen**: `grid gap-6 lg:grid-cols-12` with 9/3 splits; action rows (`flex flex-col gap-2` title + `text-muted-foreground` subtitle); grids collapse cleanly on mobile.
3. **KPI cards** (`default/-components/metric-cards.tsx`, `finance` KPIs): label (muted, sm) → big `tabular-nums` value → delta line + sparkline (`chart.tsx` + recharts Area/Bar).
4. **Tables** (`crm` opportunities / `tasks`): toolbar (search `input` + filters + `date-range-picker`) → `table.tsx` with sortable columns, row click navigates; `skeleton` rows while loading, `empty` when zero.
5. **Charts**: `chart.tsx` + recharts (Area/Bar/Line/Composed/Pie/Funnel all used in-repo); monochrome chart ramp first, color only for severity.
6. **Map**: `logistics/-components/shipment-route-map.tsx` — SVG + `geoMercator`/`geoPath` (d3-geo) + `feature`/`mesh` (topojson-client). India choropleth = same pattern + India TopoJSON (to add).
7. **Dossier/investigation**: compose `finance/`-style cards + `file-manager/` grid/list views + timeline list + `sheet`/`dialog` for detail; status via `badge` variants.
8. **AI chat**: `(main)/chat/` thread (`bubble`, `message-scroller`) + tool-result cards rendered inline ("answer as interface").
9. **Risk color language** (only place color carries meaning): 🔴 high / 🟠 medium via `destructive`/amber named palette + `badge`; everything else stays neutral zinc.

## Density & spacing

Compact government console: `gap-6` sections, `gap-2/4` inside cards, `p-6` card padding, `text-sm` default, `size-10` icon wells in `bg-muted` rows. Match neighboring screens in card density, borders, radius, content width.

## Icons & motion

- **Icons**: `lucide-react` only (sm 16 / md 20 / lg 24). No emoji in UI.
- **Motion**: `tw-animate-css` utilities + CSS transitions; `transform` + `opacity` only, ≤300ms, `ease-out`; every animation respects `prefers-reduced-motion`. No layout-property animation.

## Anti-slop rules (for AI contributors)

1. Clone the closest existing screen first (`default`/`crm`/`finance`/`chat`/`file-manager`) — adapt, don't invent.
2. No gradients, no glassmorphism, no purple-blue AI clichés, no hero sections — this is a console, not a landing page.
3. No new fonts, no new color systems, no custom chart wrappers — `chart.tsx` + tokens cover it.
4. Every screen shows loading (`skeleton`), empty (`empty`), error, and overflow states — not just the happy path.
5. Semantic HTML, keyboard support, visible focus, labels + ARIA on interactive elements.
